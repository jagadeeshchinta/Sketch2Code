💡 1. What We Built & How It Works

A. The Problem

The gap between initial design ideation (sketches on paper napkins, notebooks, or whiteboards during sprint meetings) and a coded, clickable prototype is the single largest bottleneck in frontend product development. Translating physical sketches into clean code typically requires a 3-to-5 day turnaround, causes context loss, and consumes valuable engineering hours.

B. Our Solution

WhiteboardOS is an autonomous multimodal generative compiler that converts hand-drawn paper sketches, live camera scans, browser digital drawings, and spoken voice blueprints into functional, responsive, interactive web prototypes in under 10 seconds using Google Gemini Multimodal Vision AI.

C. End-to-End Pipeline Architecture

  1. Multimodal Ingestion Layer: Users capture UI concepts via:
    • 🎙️ Voice-to-UI Dictation ("I need a modern restaurant website with menu items, hours, and reservation form").
    • 📷 Live Optical Webcam Scanner with optical HUD viewfinder.
    • 🖼️ Photo & Sketch Upload Dropzone with client-side contrast enhancement.
    • ✍️ Digital Browser Canvas with drawing and shape tools.
  2. Spatial & Semantic Vision Engine (POST /api/analyze):
    • Extracts 2D bounding boxes (X, Y, Width, Height) for 30+ UI component types (navbars, search bars, hero headers, cards, price tags, operating hours, contact forms, buttons).
    • Performs strict domain-specific OCR reading handwritten labels accurately.
    • Assigns confidence scores (0–100%) for every detected component.
  3. Real-Time Code Synthesis Engine (POST /api/generate/stream):
    • Streams production-ready HTML5 + CSS + React JSX token-by-token via Server-Sent Events (SSE) into an animated macOS-style terminal HUD.
    • Injects the signature "Liquid Glass" design system (dark obsidian backgrounds, frosted glass blur, specular highlights).
  4. Sandboxed Living Prototype & Conversational Iteration:
    • Renders the prototype in an isolated, secure iframe sandbox with interactive state.
    • Allows natural language conversational updates ("Make buttons glowing amber", "Add 3 pricing tiers") with version time-travel and 1-click ZIP export.

⚡ 4. Key Features, Technical Decisions & Challenges Solved

A. Key Features

  • Multimodal Ingestion: Voice dictation, photo upload, live camera viewfinder, digital canvas board, and golden sample chips.
  • 30+ Component Hierarchy: Accurately classifies navbars, hero headers, informational cards, menus, hours, locations, search inputs, buttons, and forms with confidence scores.
  • Live Token Terminal: Real-time code streaming in a macOS-style developer terminal.
  • Living Interactive Sandbox: Functional buttons, forms, search inputs, and responsive layout.
  • Conversational Iteration: Natural language prompts modify existing prototype code without losing styling.
  • Version History Time-Travel: Instant branching and rollback across all prototype versions.
  • Production ZIP Export: 1-click export of ready-to-deploy index.html, styles.css, and Component.jsx.

B. Technical Decisions & Challenges Overcome

Challenge 1: Resolving LLM Domain Bias
Problem: Initial vision prompts were biased toward generic SaaS dashboards, generating metric cards even when given restaurant menus or e-commerce wireframes.
Solution: Re-engineered ANALYSIS_SYSTEM_PROMPT with strict OCR text extraction and domain-aware routing rules, ensuring sketches with "MENU", "HOURS", "LOCATION", or "PRICE" synthesize authentic restaurant websites with real dish cards and reservation forms.
Challenge 2: Robust Image Ingestion across Formats
Problem: Data URLs in varying formats (UTF-8 SVGs, WebP canvas blobs) caused Gemini base64 decoding errors.
Solution: Engineered parseImageData in src/app/api/analyze/route.ts to handle Base64, raw SVG XML, and multipart data seamlessly.
Challenge 3: Vercel Serverless Function Timeouts
Problem: Deep multimodal code synthesis takes 15–20s, exceeding default Vercel function timeouts (10s).
Solution: Configured export const maxDuration = 60 and export const dynamic = "force-dynamic" across all Next.js App Router API routes.
