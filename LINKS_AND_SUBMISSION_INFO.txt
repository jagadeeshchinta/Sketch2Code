2. PROJECT HIGHLIGHTS & ARCHITECTURE
--------------------------------------------------------------------------------
• Multimodal Ingestion : Voice-to-UI dictation, paper sketch upload, live webcam scanning, digital canvas drawing.
• Vision AI Pipeline   : Google Gemini 2.5/3.5/3.6 Multimodal Vision API with multi-model cascade and multi-key rotation.
• Offline CV Fallback  : In-browser HTML5 Canvas spatial density analyzer and compiler for 100% offline resilience.
• AST Self-Healing     : DOM validator that strips unverified scripts, auto-balances unclosed tags, and injects viewport metas.
• Real-time SSE Stream : Live code streaming into an animated macOS developer terminal HUD.
• Living Sandbox       : Interactive iframe sandbox with conversational AI natural language iteration.
